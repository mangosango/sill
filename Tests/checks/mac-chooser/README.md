# `mac-chooser`

**Checks:** the Mac viewer's chooser: identity-based row grouping, confirmed-link and cancellation wiring, and
keyboard affordances; with `--mutants`, eight source and policy mutations it must reject. It does not
launch the viewer or show its layout.

**Compiles:** `MacClient/ViewerConnectView.swift` (read as source) and `iOSClient/DiscoveryPolicy.swift`'s grouping rules
